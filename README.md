# UMDSoccer

## *Overview*  
This project structures and analyzes UMD men's soccer data to provide insights into team performance, game statistics, and player contributions. The analysis includes database design, SQL queries, and trend evaluations to improve team management and enhance data-driven decision-making.

## *Key Findings*  
- **Game Performance Trends**: Identifies the distribution of goals, assists, and penalties across different games and seasons.
- **Player and Team Insights**: Pinpoints key contributors and evaluates player performance based on historical game data.
- **Data-Driven Strategies**: Offers recommendations for enhancing future team performance based on the analysis of past trends.

## *Files*  
- **UMDSoccer.pptx**: Presentation covering the project background, mission, and database design.
- **Create.sql**: SQL script to create the necessary database schema.
- **Insert.sql**: SQL script to insert sample data into the database.
- **Select.sql**: SQL script to query and analyze game statistics.
- **View.sql**: SQL script to create views for game results and detailed performance analysis.

## *Technologies Used*  
- **SQL**  
- **Relational Database Design**  
- **Data Analysis**
